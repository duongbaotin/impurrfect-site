# impurrfect-site — AGENTS.md

## Stack

- **Astro 6** + **Tailwind CSS v4** (via `@tailwindcss/vite`). No React, no other framework.
- Node >= 22.12.0. ESM (`"type": "module"`).
- TypeScript via `astro/tsconfigs/strict`.

## Architecture

- `src/layouts/MainLayout.astro` — shared HTML shell with dark theme, `<Nav />`, `<Footer />`, SEO meta tags, `<ClientRouter />` (Astro 6 — not `ViewTransitions`), skip-link utility, Google Fonts link (Playfair Display only), print styles.
- Expects optional `title`, `description`, and `allergyNotice` (boolean) props. `allergyNotice` passed to `<Footer />`.
- Font utilities: `.font-display` and `.font-body` from `@theme` in `global.css`. `.font-accent` (italic, Freight Big Pro → Playfair Display fallback) defined in `MainLayout`'s `<style is:global>`. **Do not** use Tailwind's `fontFamily` theme config. Satoshi and Freight Big Pro are declared but not loaded — they resolve to system fallbacks.
- Brand colors defined as Tailwind theme variables in `src/styles/global.css`: `night` (`#0F0F12`), `cream` (`#F6F3EF`), `gold` (`#875A2A`), `gold-dark` (`#6b4620`), `charcoal` (`#33363A`). Use `bg-night`, `text-cream`, `text-gold`, `border-charcoal`, etc. — never raw hex values.
- Price formatting: Vietnamese Dong with "k" shorthand, e.g. `VND 180k`.
- Images in `public/` referenced as absolute paths (`/hero.svg`).
- `src/styles/global.css` = imports Tailwind and defines `@theme`. Imported only by `MainLayout`.
- `src/components/HoursLocation.astro` — pre-built venue info block. Import instead of duplicating markup.
- Sitemap auto-generated by `@astrojs/sitemap`. Config has `site: 'https://impurrfect-bar.meowracle.space'`.
- Vercel deployment via `vercel.json` with `cleanUrls: true` and two permanent redirects: `/bar-menu` → `/menu`, `/bar-menu/:path*` → `/menu/:path*`.

## Content Collections

Menu data lives in Content Collections for type safety.

| File | Purpose |
|---|---|
| `src/content.config.ts` | Zod schema, `glob` loader matches `src/content/menu/*.yaml` |
| `src/content/menu/*.yaml` | One file per menu item |
| `src/data/categories.ts` | Category metadata (name, description, sort order) |
| `src/data/menu.ts` | TypeScript types (`MenuItemData`, `MenuCategoryData`) |

### YAML fields

```yaml
name: string
price: string          # e.g. "VND 180k"
description: string
category: string       # must match a name in categories.ts
order: number          # sort position within category (defaults to 0)
tags?: string[]        # e.g. ["Smoky", "Bitter"]
featured?: boolean     # shows ★ Bartender's Pick badge
image?: string         # path to thumbnail in public/, e.g. "/cocktail-placeholder.svg"
subcategory?: string   # optional grouping within a category, e.g. "Whiskey-based"
available?: boolean    # default true; set false to show "Currently unavailable"
```

### Data flow (menu page)

`getCollection('menu')` → sort by `order` → filter by `category` matching `categories.ts` → map `.data` to `MenuItemData`. **Items with a `category` that doesn't match `categories.ts` are silently dropped.** `MenuItemData` (in `src/data/menu.ts`) does not include `category` or `order` — those live on the collection entry wrapper, not on `item.data`. Default `order` is `0` (sorts before any positive number).

When changing the menu item schema, update all in sync: `src/content.config.ts`, `src/data/menu.ts`, `CONTENT-GUIDE.md`, and `src/content/menu/TEMPLATE.md`.
