# impurrfect-site — AGENTS.md

## Stack

- **Astro 6** + **Tailwind CSS v4** (via `@tailwindcss/vite`). No React, no other framework.
- Node >= 22.12.0. ESM (`"type": "module"`).
- TypeScript via `astro/tsconfigs/strict`.

## Commands

| Command | Action |
|---------|--------|
| `npm run dev` | Dev server at `localhost:4321` |
| `npm run build` | Build to `./dist/` |
| `npm run preview` | Preview production build |
| `npm run check` | Type-check all `.astro` files via `@astrojs/check` |
| `npm run astro` | CLI wrapper (`astro add`, etc.) |

No tests, no linter, no formatter config in this repo.

## Routes

- `/` — landing page
- `/bar-menu` — cocktail menu listing
- `/about` — brand story / hours / location
- `/contact` — contact info and inquiry note
- `*` — 404 page (branded)

## Architecture

- All pages use `src/layouts/MainLayout.astro` — shared HTML shell with dark theme (`#0F0F12` bg, `#F6F3EF` text), `<Nav />`, `<Footer />`, SEO meta tags, and Google Fonts (`Playfair Display`).
- Font utility classes (`.font-display`, `.font-body`, `.font-accent`) are defined in `MainLayout`'s `<style is:global>`. **Do not** use Tailwind's `fontFamily` theme config.
- Brand colors (`#0F0F12`, `#F6F3EF`, `#875A2A`, `#33363A`) are used via Tailwind arbitrary values (`bg-[#0F0F12]`). No CSS custom properties.
- View Transitions via `<ClientRouter />` from `astro:transitions` (Astro 6 API — **not** the old `ViewTransitions` component).
- `src/styles/global.css` has a single line (`@import "tailwindcss"`). Imported only by `MainLayout`.
- Sitemap auto-generated by `@astrojs/sitemap`. Config has `site: 'https://impurrfect.com'` (placeholder — swap before production).
- Vercel deployment via `vercel.json` with `cleanUrls: true`.

## Content Collections

Menu data lives in Content Collections so items are type-safe and easy to add or reorder.

| File | Purpose |
|---|---|
| `src/content.config.ts` | Collection schema (zod via `astro/zod`), `glob` loader matches `src/content/menu/*.yaml` |
| `src/content/menu/*.yaml` | One file per menu item |
| `src/data/categories.ts` | Category metadata (name, description, sort order) |
| `src/data/menu.ts` | Shared TypeScript types (`MenuItemData`, `MenuCategoryData`) |

### YAML fields

```yaml
name: string
price: string          # e.g. "VND 180k"
description: string
category: string       # must match a name in categories.ts
order: number          # sort position within category
tags?: string[]        # e.g. ["Smoky", "Bitter"]
featured?: boolean     # shows ★ Bartender's Pick badge
image?: string         # path to thumbnail in public/, e.g. "/cocktail-placeholder.svg"
```

To add a new menu item: create a new `.yaml` file, commit, and Vercel auto-deploys.

## Style conventions

- All colors via Tailwind arbitrary values (`bg-[#0F0F12]`), never theme variables.
- Font classes via `.font-display`, `.font-body`, `.font-accent` utilities.
- Price formatting: Vietnamese Dong with "k" shorthand, e.g. `VND 180k`.
- Images in `public/` referenced as absolute paths (`/hero.svg`).
